# TechBairro

Sistema de cadastro e gerenciamento de clientes.

## Sobre o projeto

O TechBairro foi desenvolvido em Python para facilitar o cadastro,
consulta, atualização e remoção de clientes.

## Funcionalidades

- Cadastrar clientes
- Consultar clientes
- Atualizar dados
- Remover clientes
- Armazenar informações no banco de dados
- Validar dados cadastrados

## Tecnologias utilizadas

- Python
- Tkinter
- SQLite

## Como executar

Para iniciar o sistema, execute o arquivo:

`techbairro.py`

## Banco de dados

O sistema utiliza o banco de dados `techbairro.db`
para armazenar os clientes.

## Versão
