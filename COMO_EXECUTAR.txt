TechBairro 3.2.1

Requisitos
- Python 3
- Bibliotecas utilizadas: tkinter, sqlite3 e os.
- No Linux, pode ser necessário instalar o Tkinter.

Como executar
1. Extraia o arquivo TechBairro-3.2.1.zip.
2. Abra um terminal dentro da pasta do projeto.
3. Execute:
   python techbairro.py

Dados
- O arquivo techbairro.db é criado na primeira execução.
- Faça cópias do arquivo techbairro.db para não perder os clientes cadastrados.
